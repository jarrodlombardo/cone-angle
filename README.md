# cone-angle

Foundry VTT Module that adds a setting for cone angle.

## Installation and Setup

Option 1: Install via the usual foundry package manager. <https://foundryvtt.com/packages/cone-angle>

Option 2: Install by pasting the latest released [module.json](https://github.com/jarrodlombardo/cone-angle/releases/latest/download/module.json) in the module installer's `Manifest URL` box.

After installing, remember to enable the module in the world so you can use it.
